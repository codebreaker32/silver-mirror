Deep Teal, clinic-free.

A petrol-teal accent on warm putty neutrals. It should read like a well-run neighbourhood pharmacy counter: precise, plain-spoken, nothing to sell you. Teal is kept for actions and focus only. It never marks a verdict, so FITS (sage), CAUTION (ochre) and UNKNOWN (slate) carry no brand colour. Schibsted Grotesk sets headings and reasons with a sturdy, newsprint confidence. Atkinson Hyperlegible Next, drawn so that letters like I, l and 1 cannot be confused, sets ingredient names such as "isopropyl myristate" so a fast, non-native reader gets them right.

01 / CHECK

The verdict screen, CAUTION state

Reasons are set larger than the label: the label frames the reasons, it doesn't replace them. Each reason starts with the scan moment, then the ingredient and why it matters, then a link back to the reading's band chip. The actions stay pinned and name where they go. Both frames scroll. The dark frame opens at the end so that, between them, the whole screen is visible.

02 / PROFILE

Readings as band chips

Bands only, never numbers. Each band is written out in words, and the three-step meter only repeats it. There are no skin-colour swatches anywhere. "Feels wrong? Edit" sits on the card itself; in the light frame it is shown in its keyboard-focus state to demo the focus ring token.

03 / VERDICTS

Four states, never colour alone

Each state has a text label, a unique icon shape and its own hue. CAUTION uses a half-filled circle ("partly fits"), not a warning triangle. UNKNOWN uses a dashed, incomplete circle. The medicine gate has no verdict label: just an ink outline, a pharmacist-at-counter icon and the one fixed line.
