## How the values got here

- Started from clay-ink.tokens.json values (86 pairs, all passing) and applied the judge fixes before gating.
- text-muted light #655B4D -> #564D41 (sand.700) so a real third level fits: text-subtle #6B6152 still reaches 4.77:1 on bg-sunken. Dark text-subtle sand.450 #9E9282 reaches 5.01:1 on surface-raised (and 4.68:1 as disabled-fg on the sand.850 disabled fill).
- border-strong unified to sand.500 #807464 in both modes (lowest: 3.35:1 on dark surface-raised; 3.58:1 on light bg-sunken).
- Dark accent #B0C5C7 (read as disabled) -> ink.300 #86A4A7 with ink.950 #0C171A text, 6.84:1. Dark accent-pressed ink.400 redefined #5E8286 -> #6B8C90 so the label still reaches 5.01:1. Dark focus ring moved to ink.200 so it stays visible around the deepened button.
- Verdict borders raised from decorative hairlines (#3F5534 / #5E4920 in dark, about 1.4:1) to the 500 step of each hue, gated at 3:1 against bg and surface in both modes. Fixes the dark CAUTION edge that disappeared.
- Verdict icons get their own 600 (light) / 400 (dark) step: CAUTION icon #8A5D12 is 4.65:1 on its tint, above the Deep Teal fix target #95620F (4.22:1 here).
- Meter filled moved from chip-fg to sand.800 / sand.150 (neutral ink); empty stays a full-opacity border-strong outline.
- Checker first run: 228 pairs, 0 contrast failures, 2 lint failures (both rule false-positives: HSL saturation overstated near-white sand; the mortar-and-pestle test matched the 'no mortar' note). Rules corrected; negative test with six planted defects caught all six.
- v1.1 (critique round 2). Verdict head: inset 3dp stripe deleted (no rule token); sentence set in Newsreader type.verdictLine 20/26; 1dp tinted border; radius.lg 12. FITS and CAUTION heads have near-equal luminance, so the 24dp silhouette and the caps label carry the difference in greyscale (documented, not hidden).
- v1.1. UNKNOWN head moved off cool slate onto warm paper (sand.150 light / sand.850 dark) with a dashed border, so it no longer reads as the ink 'info, tap me' family. Dark FITS and CAUTION fills desaturated about 30% (moss.900 #1E2A1A -> #1F281C, ochre.900 #2D2313 -> #292217).
- v1.1. Dark accent-subtle ink.900 -> ink.700 #253D41 so the selected nav pill reads (1.33:1 on the bar, matching light); ink.100 on it is 8.55:1. Nav selection is carried by weight (600 vs 400) and a 2.25 stroke, not colour alone.
- v1.1. New focus-ring-inverse (ink.200 light / ink.700 dark) for the snackbar, and focus-ring-overlay (white + 1dp rgba(0,0,0,0.6) halo) for camera controls; both gated.
- v1.1. Medicine head is no longer a box: verdict.medicine.bg = the screen bg and component borderWidth 0. The pharmacist icon gains one bottle on the counter.
- v1.1. Shadow colour is a primitive (sand.shadow #423B32) aliased through color.shadow; dark is transparent.
- v1.1. Reason line 18/26 400 -> 19/26 500 with a 6dp fact gap; display and title use a bundled Newsreader 36pt optical-size instance in RN (opsz axis on the web).
